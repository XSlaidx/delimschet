Политика конфиденциальности

Приложение «Делим Счёт» (Telegram Mini App, бот @delimschet_bot)

Мы относимся к вашим данным бережно и собираем только то, что необходимо для работы группового кошелька. Настоящий документ объясняет, какие данные обрабатываются и зачем.

1. Какие данные мы собираем

  • Данные Telegram. При открытии Mini App мы получаем ваш идентификатор пользователя Telegram (user id), имя (first_name) и ссылку на аватар (photo_url) через официальный механизм initDataUnsafe. Эти данные используются только для того, чтобы показать вас в списке участников кассы.
  • Содержимое кассы. Название кассы, список участников (имена и, если указаны, реквизиты для перевода — номер карты / IBAN / телефон), траты, опросы, сборы и долги. Эти данные привязаны к идентификатору комнаты (room id).
  • Локальные данные устройства. Список «частых участников» и все ваши кассы хранятся в браузере устройства (localStorage) для быстрого доступа и работы офлайн.

2. Где хранятся данные

  • Данные касс синхронизируются и хранятся в облачной базе данных Supabase (проект на серверах в ЕС). Доступ к конкретной кассе имеют только те, у кого есть её ссылка (room id).
  • Локальное хранилище (localStorage) остаётся на вашем устройстве и не передаётся третьим лицам.

3. Как мы используем данные

  • Для расчёта балансов, долгов и переводов между участниками кассы.
  • Для отправки уведомлений в чат, если вы привязали бота к группе (команда /bind).
  • Мы не используем данные для рекламы, аналитики третьих лиц или передачи коммерческим партнёрам.

4. Кому доступны данные

  • Любой человек с ссылкой на кассу (deep link вида t.me/delimschet_bot/app?startapp=ID) может видеть её содержимое. Не публикуйте ссылку в открытых источниках, если не хотите этого.
  • Команда разработки имеет технический доступ к облачной базе для поддержки и резервного копирования.

5. Удаление данных

  • Удаление участника, траты или сбора внутри приложения удаляет их из текущей кассы.
  • Для полного удаления своих данных (или кассы целиком) напишите в поддержку бота @delimschet_bot с указанием room id. Запрос обрабатывается в течение 30 дней.
  • Очистка данных браузера на устройстве удаляет локальный список касс и частых участников.
